# FIELD / NOTES — 이지환 · AI Educator

기업 AI 교육과 프로젝트 코칭 이력을 소개하는 반응형 포트폴리오 사이트입니다.

## 실행

정적 파일을 웹 서버에서 제공하면 됩니다. `index.html`, `style.css`, `app.js`, `records.json`은 같은 폴더에 있어야 합니다.

## 이력 데이터

`records.json`에서 전체 이력과 날짜별 진행 건을 관리합니다. `experience.txt`는 검색 기능을 사용할 수 없는 환경을 위한 읽기용 목록입니다. `PORTFOLIO_PLAN.md`에는 화면 설계와 이력 표시 기준이 정리되어 있습니다.
